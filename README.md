# children-shelter-project

Кошторис дитячого притулку.

## Збірники базових норм ДСТУ Б Д

У каталозі [`dstu-b-d/`](dstu-b-d/) зібрано структуру ресурсних елементних кошторисних норм (РЕКН):

- **Д.2.2** — 47 збірників будівельних робіт
- **Д.2.3** — 39 збірників монтажу устаткування
- **Д.2.4** — 20 збірників ремонтно-будівельних робіт
- **Д.2.5 / Д.2.6 / Д.2.7** — реставрація, пусконалагодження, машини

Детальні групи й норми сформовано для пріоритетних збірників будівництва/ремонту притулку. Плоский експорт: `dstu-b-d/exports/priorytet-prytulok.csv`.

Докладно: [dstu-b-d/README.md](dstu-b-d/README.md).

```bash
python3 dstu-b-d/scripts/generate_catalogs.py
```
